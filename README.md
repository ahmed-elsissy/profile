# إيملي نوتس | EMLENotes — الموقع التعريفي الرسمي وسابقة الأعمال

الموقع الرسمي لشركة **إيملي نوتس (EMLENotes)** — شركة تقنية مصرية تبني البنية التحتية الرقمية للتعليم الطبي، الحوكمة الأكاديمية، بنوك الأسئلة الطبية، الذكاء الاصطناعي، وإنتاج المحتوى الطبي.

---

## 📁 هيكل الموقع المتعدد الصفحات

```text
├── index.html          # الصفحة الرئيسية (ملخص المنظومة، الأرقام الموحدة، أبرز الحلول والمشاريع)
├── about.html          # من نحن (القصة، الرؤية والرسالة، تحولات السوق، وفلسفة التصنيع التقني الداخلي)
├── solutions.html      # الحلول والمنتجات (الاستضافة، QBank، الحضور، إنتاج المحتوى، CME، والذكاء الاصطناعي)
├── attendance.html     # صفحة منظومة الحضور والحوكمة الأكاديمية (مسارات الرصد، الأدوار، ولوحات القيادة)
├── projects.html       # سابقة الأعمال والشراكات (دراسات حالة مفصلة قابلة للتصفية حسب المجال)
├── roadmap.html        # الرؤية المستقبلية وخارطة الطريق (المراحل الثلاث + الحرم الطبي الافتراضي VR)
├── contact.html        # تواصل معنا ونموذج حجز عرض توضيحي حي (Live Demo)
├── privacy.html        # سياسة الخصوصية وحماية البيانات الأكاديمية
├── terms.html          # الشروط والأحكام
├── css/
│   └── main.css        # نظام التصميم الموحد (Design Tokens, Layout, Coverflow, Cards, Responsive)
├── js/
│   └── app.js          # التفاعلات (قائمة الموبايل، Coverflow 3D، Lightbox، فلاتر المشاريع، ونموذج التواصل)
└── assets/
    └── img/            # الصور واللقطات المحسنة بصيغة WebP وأيقونات المعاينة (OG Cover & Favicons)
```

---

## 🌿 الفروع

- `dev`: فرع التطوير والمعاينة.
- `main`: فرع الإنتاج.
